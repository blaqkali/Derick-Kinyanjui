## 🔬 Featured Projects

### 1. Hybrid Finite Difference–Physics-Informed Neural Networks

**Status:** In progress

My final-year research project investigates a hybrid approach to solving partial differential equations in complex computational geometries.

- Implementing classical finite difference methods as numerical baselines.
- Developing physics-informed neural networks using PyTorch.
- Investigating finite difference approximations within the HFD-PINN framework.
- Exploring signed distance functions for representing irregular domains.
- Comparing solution accuracy, convergence behaviour, computational cost, and numerical errors.

**Technologies:** Python, PyTorch, NumPy, Matplotlib.

### 2. Numerical Methods for Differential Equations

A collection of numerical implementations exploring how mathematical methods can be used to solve ordinary and partial differential equations.

- Numerical solutions of ODEs using Euler and Runge–Kutta methods.
- Finite difference approximations of spatial derivatives.
- Numerical solutions of heat and wave equations.
- Compact finite difference schemes and Crank–Nicolson time integration.
- Numerical stability, convergence, and error analysis.

**Technologies:** Python, NumPy, Matplotlib.

### 3. Convolutional Neural Networks for Image Classification

Exploring deep learning through the implementation and evaluation of convolutional neural networks for image classification.

- Implementing CNN architectures using PyTorch.
- Exploring batch normalization, dropout, and data augmentation.
- Monitoring training loss and classification accuracy.
- Evaluating model generalization on unseen data.

**Technologies:** Python, PyTorch, NumPy, Matplotlib.

### 4. Machine Learning and Data Analysis

Practical machine learning and exploratory data analysis projects focused on extracting insights from real-world datasets.

- Data cleaning and exploratory data analysis.
- Numerical and categorical feature preprocessing.
- Leakage-safe preprocessing pipelines.
- Model training, validation, and performance evaluation.
- Data visualization and interpretation of results.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
